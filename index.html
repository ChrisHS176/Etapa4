Módulo 01

1. Funciones predefinidas de JavaScript

JavaScript incluye funciones y métodos integrados en el lenguaje listos para usarse sin necesidad de programarlos desde cero.

1.1

Funciones de conversión de tipos de datos

parseFloat()

Global

Analiza una cadena de texto y devuelve un número de punto flotante (con decimales). Extrae el número inicial hasta encontrar un carácter no numérico. 

let texto = "19.95 USD";
let num = parseFloat(texto);
// Resultado: 19.95 (number)
⚡ Pruébalo en vivo
Valor: 45.78 | typeof: "number"

Number()

Constructor

Convierte estrictamente todo el valor recibido a un número (entero o decimal). Si contiene letras o texto adicional, devuelve NaN (Not a Number). 

Number("123.4"); // 123.4
Number(true);    // 1
Number("12px");  // NaN
⚡ Pruébalo en vivo
Valor: 100.5 | typeof: "number"

parseInt()

Global

Analiza una cadena y devuelve un número entero (descarta decimales sin redondear). Opcionalmente acepta una base numérica (radix, ej. 10 o 2). 

parseInt("99.99", 10); // 99
parseInt("1010", 2);   // 10 (binario)
⚡ Pruébalo en vivo
Valor: 89 | typeof: "number"
1.2

Funciones de manipulación de cadenas (String)

concat()

String.prototype

Une dos o más cadenas de texto y devuelve una nueva cadena combinada sin modificar las originales. 

let saludo = "Hola";
let full = saludo.concat(" ", "Mundo");
// "Hola Mundo"
⚡ Pruébalo en vivo
"JavaScript es genial!"

substring()

String.prototype

Extrae caracteres de una cadena entre dos índices: inicio (incluido) y fin (excluido). 

let txt = "Programación";
txt.substring(0, 8);
// "Programa"
⚡ Pruébalo en vivo
"Desarrollo"

split()

String → Array

Divide una cadena de texto en un arreglo (Array) de subcadenas utilizando un separador especificado (como coma, espacio o guion). 

let lista = "HTML,CSS,JS";
lista.split(",");
// ["HTML", "CSS", "JS"]
⚡ Pruébalo en vivo
["rojo", "verde", "azul"] (length: 3)
1.3

Funciones de manipulación de arrays

Estado en memoria del Array activo:
let frutas = ["Manzana", "Banana", "Naranja"];

push()

Muta el Array

Agrega uno o más elementos al final del array y devuelve la nueva longitud (length) del arreglo. 

let len = frutas.push("Uva");
// len = 4
// frutas = [..., "Uva"]
⚡ Pruébalo en vivo
Pulsa ejecutar para agregar al array superior.

pop()

Muta el Array

Elimina el último elemento de un array y devuelve ese elemento eliminado. Si el array está vacío, devuelve undefined. 

let ultimo = frutas.pop();
// ultimo = "Naranja"
// frutas = ["Manzana", "Banana"]
⚡ Pruébalo en vivo

Pulsa ejecutar para extraer el último elemento.

join()

Array → String

Une todos los elementos de un array en una sola cadena de texto, separados por el delimitador que indiques (por defecto es una coma). 

let texto = frutas.join(" - ");
// "Manzana - Banana - Naranja"
⚡ Pruébalo en vivo
"Manzana | Banana | Naranja"
1.4

Funciones de matemáticas (Objeto Math)

Math.abs()

Valor Absoluto

Devuelve el valor absoluto de un número (convierte cualquier número negativo en positivo; los positivos y el cero permanecen igual). 

Math.abs(-42.5); // 42.5
Math.abs(15);    // 15
⚡ Pruébalo en vivo
Math.abs(-27.8) = 27.8

Math.max()

Valor Máximo

Devuelve el número más grande de entre cero o más números proporcionados como argumentos. 

Math.max(12, 85, 34, 9); // 85
⚡ Pruébalo en vivo
Math.max(14, 92, 5, 67, 31) = 92

Math.random() * rango

Aleatoriedad

Math.random() genera un decimal pseudoaleatorio entre 0 (incluido) y 1 (excluido). Al multiplicarlo por un rango, escalamos el resultado entre 0 y ese rango. 

let rango = 100;
let aleatorio = Math.random() * rango;
// Ej: 73.418291042...
⚡ Pruébalo en vivo
Decimal: 48.2914 | Entero (Math.floor): 48

Math.pow()

Potencia

Devuelve la base elevada a la potencia del exponente (equivalente a base ** exponente). 

Math.pow(2, 8); // 2^8 = 256
Math.pow(5, 3); // 5^3 = 125
⚡ Pruébalo en vivo
Math.pow(2, 10) = 1024
Módulo 02

2. Funciones definidas por el programador

Son bloques de código reutilizables creados por nosotros para realizar tareas específicas mediante la palabra clave function.

2.1 Invocación de una función

Declaración vs. Invocación

Definir una función solo guarda las instrucciones en memoria; no las ejecuta. Para ejecutar el código interno, debemos invocarla (llamarla) escribiendo su nombre seguido de paréntesis () y enviando sus argumentos. 

// 1. Declaración de la función
function saludarUsuario(nombre, rol) {
    let mensaje = `Hola ${nombre}, tu rol es ${rol}.`;
    return mensaje;
}

// 2. Invocación de la función con argumentos
saludarUsuario("Sofía", "Desarrolladora");

Módulo 03

3. Funciones que devuelven un resultado: RETURN

La sentencia return finaliza inmediatamente la ejecución de la función y entrega un valor de salida hacia el punto donde fue llamada.

Captura y reutilización de resultados

Gracias a return, podemos almacenar el resultado de una función dentro de una variable y utilizarlo en otras operaciones matemáticas o lógicas. Además, cualquier código escrito después de un return ejecutado nunca se alcanzará. 

function calcularTotalConIVA(precio, porcentajeIVA) {
    let impuesto = precio * (porcentajeIVA / 100);
    let total = precio + impuesto;
    return total; // Devuelve el valor y termina
    // console.log("Esto nunca se ejecuta");
}

let factura = calcularTotalConIVA(500, 16);
⚡ Pruébalo en vivo: Flujo con RETURN
1. Entrada: calcularTotalConIVA(500, 16)
2. Sentencia return entrega: 580
3. Variable almacenada: let factura = 580 (typeof: "number")
Módulo 04

4. Variables en una función: GLOBALES Y LOCALES

El alcance (scope) determina desde qué partes del programa se puede leer o modificar una variable.

Variables Globales

Se declaran fuera de cualquier función. Son accesibles y modificables tanto desde el código principal como desde el interior de cualquier función.

let contadorGlobal = 10; // Visible en todo el archivo

Variables Locales

Se declaran dentro de una función (con let, const o var). Solo existen mientras la función se ejecuta; intentar leerlas desde fuera genera un ReferenceError.

function test() { let secreta = "ABC"; } // Solo vive aquí
⚡ Laboratorio Visual de Alcance (Scope)

Observa cómo interactúan la memoria Global y el bloque Local

// ÁMBITO GLOBAL
let puntajeGlobal = 100;

function jugarNivel() {
    // ÁMBITO LOCAL (exclusivo de jugarNivel)
    let bonoLocal = 50;
    puntajeGlobal += bonoLocal; // Modifica la global
    return { puntajeGlobal, bonoLocal };
}
🌍 ÁMBITO GLOBAL (Siempre activo) puntajeGlobal = 100
📦 ÁMBITO LOCAL: jugarNivel() Inactivo (en espera)
Estado inicial: puntajeGlobal vale 100. bonoLocal aún no existe en memoria.
